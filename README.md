# Show Milhão

Projeto de quiz estilo “Show do Milhão” feito em HTML, CSS e JavaScript.

## Como rodar

1. Clone o repositório  
2. Abra o arquivo `index.html` no navegador  

## Tecnologias

- HTML  
- CSS  
- JavaScript  

## Funcionalidades

- Perguntas com múltiplas escolhas  
- Sistema de pontuação  
- Botão para encerrar e salvar pontuação
